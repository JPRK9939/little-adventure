# เกมผจญภัยเล็กๆ สำหรับคนพิเศษ ♡

เกม 3D สไตล์ pixel บนเว็บ (PC, จอแนวนอน 16:9) โลกเริ่มต้นเป็นสีขาวดำ แล้วค่อยๆ กลับมามีสีสันเมื่อเล่นไปจนจบ

## เล่นเลย

https://jprk9939.github.io/little-adventure/

## เนื้อเรื่องโดยย่อ

1. กรอกชื่อ (รับเฉพาะชื่อที่กำหนด หรือกด 🎲 สุ่ม) → ตกลงไปในโลกไร้ขอบฟ้า
2. ฝึกเดิน หันกล้อง วิ่ง กระโดด → เจอตุ๊กตาหมา "น้ำตาล" ที่จะคอยบอกทาง
3. หมียักษ์ใส่แว่นตกลงมา → วิ่งหนี 1 นาที → เก็บค้อนวิเศษ → สู้กับหมี
4. หมีโกรธลุกเป็นไฟ → เก็บวัตถุดิบมาทำแซนวิช → กระโดดป้อนตอนหมีเหนื่อย
5. โลกกลับมามีสีสัน → ลูบหัว → end credits
6. เล่นจบแล้ว หน้าแรกจะเปลี่ยนเป็นเกม "ทุบหัวหมี" (60 วินาที) และมีปุ่มเริ่ม story ใหม่

## ปุ่มควบคุม

| | |
|---|---|
| เดิน | W A S D |
| หันกล้อง | เมาส์ |
| วิ่ง | Shift + W A S D |
| กระโดด | Space |
| หยิบ / ใช้ | E |
| ทุบด้วยค้อน | คลิกซ้าย |
| หันไปดูหมี | คลิกขวาค้าง |
| ดิ้นให้หลุด | Space รัวๆ |
| ตั้งค่า (เสียงเพลง / เอฟเฟกต์ / เต็มจอ / ออกจากเกม) | ปุ่ม ⚙️ มุมขวาบน |

## โครงสร้างไฟล์

- `index.html` หน้าเว็บ, UI และธีม
- `game.js` ตัวเกมทั้งหมด (เนื้อเรื่อง, การต่อสู้, ทุบหัวหมี, เซฟ)
- `audio.js` เพลงและเสียงทั้งหมด สังเคราะห์สดด้วย Web Audio (ไม่มีไฟล์เสียง)
- `characters.js` **ชุดตัวละครที่ใช้ซ้ำได้**: ผู้หญิง/ผู้ชายตัวขาว (หน้าปกติ, `- _ -`, `^ ^`; โบว์, หมวก, แว่นกลม), ตุ๊กตาหมาน้ำตาล, หมียักษ์, ค้อน, วัตถุดิบ, แซนวิช, ต้นไม้, ดอกไม้, เมฆ

## รันในเครื่อง

```bash
python3 -m http.server 8766
```

แล้วเปิด http://localhost:8766

เกมบันทึกความคืบหน้า (จุดเซฟ, การเล่นจบ, คะแนนสูงสุด, ระดับเสียง) ไว้ใน localStorage ของเบราว์เซอร์
